# Albert Sans (report PDFs)

`AlbertSans-Regular.ttf` and `AlbertSans-SemiBold.ttf` are Albert Sans, by the Albert Sans
Project Authors, under the SIL Open Font License 1.1 (`OFL.txt`). They were made from the
`@fontsource/albert-sans` 5.3.0 web fonts (latin and latin-ext subsets merged, converted from
WOFF to TTF with fontTools), because ReportLab needs TrueType files. Glyphs are unchanged.
